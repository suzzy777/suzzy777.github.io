01 · About

I'm a PhD candidate in Computer Science at George Mason University, advised by Wing Lam. My research focuses on software testing and analysis — in particular, detecting, reproducing, and repairing flaky tests: tests that pass and fail non-deterministically on the same version of code.

I build heuristics and large-language-model-based tools that make regression testing faster and more reliable, with recent work on ranking and efficiently searching for the tests responsible for order-dependent flaky failures. Expected graduation: May 2027.

03 · Selected Research

ReproFlake: a dataset of reproducible flaky-test failures

Flaky failures are notoriously hard to reproduce, which makes them hard to study and repair. ReproFlake provides 1,115 reproducible flaky tests with containerized environments, reproduction and validation scripts, and execution logs — plus an analysis of what makes flaky failures hard to reproduce and how fixes differ across flakiness categories.

Optimizing search for OD-relevant tests

Enhances the delta-debugging search used in iFixFlakies to find the tests responsible for order-dependent failures with far fewer test executions, guiding the search with hierarchical information, historical execution data, TF-IDF similarity, and LLM-based similarity.

Delta debuggingTF-IDFLLMsPythonMaven

Ranking relevant tests for order-dependent flaky tests

Order-dependent flaky tests pass or fail depending on the order tests run in. This work introduces two methods to rank the tests likely responsible for order-dependent failures: an LLM-based analysis of test method content, and statistical analysis over historical test-order execution data.

ChatGPT and software testing education

An empirical study of how well ChatGPT answers common questions from a popular software testing curriculum, examining both its promise as a learning aid and its risks in the classroom.
