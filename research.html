Research

Detecting, repairing and reproducing flaky tests, which are tests that pass and fail non-deterministically on the same version of code.

Projects

  1. Flaky tests

    A Dataset of Reproducible Flaky-Test Failures

    Flaky tests may pass or fail inconsistently when executed on the same code version, making them difficult to reproduce and repair. This work introduces ReproFlake, a dataset of 1,115 reproducible flaky tests. The dataset includes reproducible environments, reproduction and validation scripts, and execution logs to support research on flaky-tests. The work also analyzes the challenges of reproducing flaky failures and the characteristics of flaky-test fixes across different flakiness categories.

  2. Flaky tests

    Optimizing Search for Tests Relevant to Order-Dependent Flaky Tests

    This work improves the process of finding the tests responsible for order-dependent failures by enhancing the delta-debugging search used in iFixFlakies. The proposed techniques use hierarchical information, historical execution data, TF-IDF similarity, and LLM-based similarity to guide the search and reduce the number of test executions needed to locate relevant tests.

    Paper

  3. Flaky tests

    Ranking Relevant Tests for Order-Dependent Flaky Tests

    Regression testing faces challenges from flaky tests, which are tests that may pass or fail inconsistently for the same code version. A substantial type of flaky test is the order-dependent flaky test, where the outcome depends on the test execution order. This work introduces two methods to rank tests that cause order-dependent failures. The first method uses LLM to analyze the content of test methods, and the second method employs statistical analysis on past test-order execution data.
